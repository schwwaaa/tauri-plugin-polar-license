## Default Permission

Allows the app's front end to read the license status, activate a key,
release this computer's activation, and read the result of the launch check.
This is everything the bundled UI needs.

#### This default permission set includes the following:

- `allow-status`
- `allow-activate`
- `allow-release`
- `allow-launch-check`
