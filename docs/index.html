Activate once.Launch forever.

A Tauri v2 plugin for selling desktop apps with Polar.sh license keys. Customers paste their key one time. After that the app opens instantly, online or not, and is never locked in the middle of a session.

Built for software people rely on at work

If a license check can ruin your customer’s day, it shouldn’t be able to run at the wrong moment.

  • Live performance

    VJ tools, show control and stage visuals. A projector rig in a basement venue has no Wi-Fi and no patience for a license server. The plugin was designed for this case first.

  • Audio and music

    Instruments, effects hosts and DAW companions that have to open the same way at a session as they did at home.

  • Creative tools

    Editors, generators and utilities sold to individual artists, where one key per person and a simple way to move computers is all the policy you need.

  • Installations and kiosks

    Machines that run unattended and offline for months. They activate during setup and never need to reach Polar again.

  • Developer tools

    Paid desktop utilities from indie developers who want Polar’s checkout, taxes and keys without writing the client side themselves.

What happens, start to finish

Polar handles payment, tax and the key itself. The plugin handles everything inside your app.

  1. The customer buys on Polar

    Your Polar product carries a License Keys benefit with an activation limit, for example one or three computers. Polar issues the key.

  2. They paste the key once

    The activation screen sends it to Polar, which records this computer as one activation. This is the only step that needs the internet. The plugin then starts your real app through an on_licensed hook.

  3. Every launch after that is local

    The app reads a license file bound to this computer and opens immediately. No network wait, ever. A copied file doesn’t work on a different machine.

  4. A quiet check runs in the background

    When there’s a connection, the plugin asks Polar whether the key is still valid. A refund or revocation takes effect at the next launch. Offline, a timeout or a hotel Wi-Fi login page changes nothing.

  5. Moving to a new computer

    “Release this machine” frees the slot so the key can move. If a computer loses its license file after a reinstall, an optional free Cloudflare Worker recognizes it and gives it its own activation back.

Messages your customers can act on

Every message says what happened and what to do next. Raw server errors go to your log, not to your customer.

Mistyped keyThat license key wasn’t recognized. Check that you pasted the whole key.
Key in use elsewhereThis license key is already activated on another computer. To move it here, open the app on the other computer and click “Release this machine”, then try again.
Key from another of your appsThis license key is for a different product.
Key revokedThis license key has been deactivated.
No connectionCouldn’t connect to the license server. Check your internet connection and try again.

Add it to your app

About fifteen lines across Rust, permissions and the front end. Full setup, including Polar, is in the docs.

Want to see it working first? The example app is a complete Tauri app you can run with your own Polar key.

  1. Add the crate

    # src-tauri/Cargo.toml
[dependencies]
tauri-plugin-polar-license = { git = "https://github.com/schwwaaa/tauri-plugin-polar-license" }

  2. Register the plugin

    Give it your Polar IDs and tell it what to start once the license is valid.

    tauri::Builder::default()
    .plugin(
        tauri_plugin_polar_license::Builder::new()
            .production("POLAR-ORG-ID", "LICENSE-KEYS-BENEFIT-ID")
            .sandbox("SANDBOX-ORG-ID", "SANDBOX-BENEFIT-ID")
            .use_sandbox(cfg!(debug_assertions))
            .support_contact("support@yourapp.com")
            .on_licensed(|app| open_main_window(app))
            .build(),
    )

  3. Allow it in a capability

    // src-tauri/capabilities/default.json
{ "permissions": ["core:default", "polar-license:default"] }

  4. Mount the activation screen

    Plain JavaScript and CSS, restylable with CSS variables. Or use the typed API to build your own.

    PolarLicenseUI.mount({
  appName: 'My App',
  onLicensed: () => startUi(),
  onReleased: () => quitApp(),
});

What it doesn’t do

Know the trade-offs before you ship. All of them are documented.

  • It isn’t DRM. Any client-side check can be patched out of an app. The activation limit and Polar’s activation records are your real controls.
  • Revocations wait for a connection. A machine that never goes online again keeps working. That’s the price of never blocking a launch.
  • Revoke is permanent in Polar. To suspend a key temporarily, disable it instead. Polar’s documentation doesn’t say this; testing against real Polar did.
  • A Windows or Linux reinstall counts as a new computer. Those systems generate a new machine ID, so the old activation needs releasing by hand.
